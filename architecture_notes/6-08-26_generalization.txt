why stratified k-fold over strat split?
Because the current dataset contains only 36 ICP-labeled images, a single 80/20 train-validation split produces only about 8 validation images. This makes validation accuracy highly unstable, since one image changes accuracy by 12.5 percentage points. Repeated stratified 80/20 splits can estimate this instability, but the same images may appear in validation multiple times while others may rarely or never be used for validation.

For this reason, stratified K-fold cross-validation is preferred. In K-fold cross-validation, the dataset is divided into K folds. The model is trained K separate times, each time using K−1 folds for training and the remaining fold for validation. Stratification preserves the low, medium, and high ICP class proportions in each fold. With 4-fold cross-validation on 36 images, each run uses approximately 27 training images and 9 validation images, and every image is used for validation exactly once. The final reported performance is the mean ± standard deviation across folds, which is more reliable than a single seeded validation split.
